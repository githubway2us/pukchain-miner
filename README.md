# 🦁 PUKCHAIN LION MINER (T320 EDITION)
ตัวขุด PUKCHAIN สำหรับเครื่อง Server T320 หรือ Ubuntu ทั่วไป

## 🛠 วิธีติดตั้ง
1. `git clone https://github.com/githubway2us/pukchain-miner`
2. `cd pukchain-miner`
3. `npm install`

## ⛏ วิธีเริ่มขุด
เปิดไฟล์ `node.js` เพื่อตั้งค่า `PAGER_ID`  จากนั้นรัน:
`node node.js`
